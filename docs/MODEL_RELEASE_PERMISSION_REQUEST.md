Subject: Permission to redistribute small research models trained on TITAN embeddings

Dear TITAN team,

We are conducting a non-commercial academic study that uses the publicly
released TCGA TITAN slide embeddings to fit cancer-specific partial least
squares models for molecular and immune-feature prediction. The fitted
artifacts contain only downstream PLS/LDA parameters and metadata; they do not
contain TITAN weights, pathology images, patch embeddings, report text or
patient-level training features.

The TITAN repository states that models trained on TITAN outputs are
derivatives and that the model and its derivatives are subject to the TITAN
terms. We would like to make the fitted PLS/LDA artifacts available with the
paper so independent academic users can apply them to their own lawfully
obtained TITAN embeddings. All use would remain non-commercial, research-only,
with prominent attribution to TITAN and a requirement that users separately
obtain access to TITAN and accept its terms.

Would you please confirm in writing whether redistribution of these small
downstream fitted artifacts is permitted? If so, please specify the required
license language, notices and repository restrictions. If redistribution is
not permitted, we will release only the complete fitting and inference code so
authorized users can reproduce the artifacts locally.

Kind regards,

[Corresponding author]
